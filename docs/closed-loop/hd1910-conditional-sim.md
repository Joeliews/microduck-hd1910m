# HD-1910 条件仿真假设

这是条件仿真的假设页，不是实测标定，也不是实机验收。本轮不建 HD 植物，不跑本地或 GPU 仿真，不把任何格子标成已执行或通过。

数只从 `servo-hd1910.md` 已经引用的来源冻结。缺的继续缺。规格书 A/0（深圳飞特 HD-1910-C001，2026-09-07）与社区 wiki 不一致的地方不取平均，条件仿真先验用规格书，不用社区页。

仓库 JSON（`hd1910_1910_m6.json`、`radxa_1910_m6.json`）自标 `actuator: sts3215`。那些 kt、R、摩擦、`command_delay`、`armature` 不进入这份先验，也不标成 HD 的估计。XL330 的 m6 同样不抄过来。

| 项 | 值 | 标记 | 随机化 |
| --- | --- | --- | --- |

| 空载速度 | 0.137 / 0.109 / 0.088 s/60° @ 4.8 / 6 / 7.4 V | spec | 规格写明 ±10% |

| 堵转电流 | 1.2 / 1.6 / 2 A @ 4.8 / 6 / 7.4 V | spec | 规格写明 ±10% |

| 额定负载 | 2.2 / 3 / 3.7 kg·cm @ 4.8 / 6 / 7.4 V | spec | 没有额外公差 |

`robot_description/` 与 RL 树里的网格、URDF 是 CAD/装配几何。它们标成 CAD，只说明连杆形状有现成网格。本页不冻结任何未在谱系里写出的长度、质量或惯量。

## 仿真前仍缺

这些没有数，不能临时编一个再标成估计。

| 项 | 标记 | 为什么还不能进先验 |
| --- | --- | --- |
| 扭矩-速度曲线 | missing | 规格只有堵转点和额定点 |
| 本机电源下的电流和限流 | missing | 规格有堵转和额定电流。总线压降、电源内阻、固件限流没有测 |
| 响应延迟 | missing | 谱系说实测前用更宽范围并标成估计，但没有给出那个范围的数 |
| 库仑、Stribeck、粘性、负载摩擦 | missing | 同上。规格书没有这些系数。`sts3215` JSON 不拿来填 |
| 齿隙分布 | missing | 只有 ≤ 0.5° 上限 |
| 输出轴惯量、电枢惯量 | missing | 规格只有整机质量。CAD 未称重的质量仍不能写成数 |
| 绕组电阻和扭矩常数的实测 | missing | 规格 Kt 仍是 7.5 kg·cm/A。JSON 的 kt、R 排除 |
| 温度、电压跌落 | missing | 没有 |
| 相对 XL330 HOME 的编码器零位 | missing | 在每台机器的标定文件里，不是 BAM `q_offset` |
| 无 manifest / ONNX `task_id` 时的 Flat / Rough / Backlash 变体 | missing | 第 15 轮的残余。已发布产物钉不住 |

条件仿真跑出来的轨迹只表示「规格先验下的仿真」。它不回写成辨识，也不填 20 格里的 HD-1910 行。
